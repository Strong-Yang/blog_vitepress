# 饮食管理

## 增肌饮食原则

### 蛋白质摄入
- 每公斤体重摄入1.6-2.2g蛋白质
- 优质蛋白来源：鸡胸肉、牛肉、鱼、蛋、奶制品

### 碳水化合物
- 训练前后适量补充
- 选择复合碳水：糙米、燕麦、红薯

### 健康脂肪
- 适量摄入：坚果、牛油果、橄榄油

## 一日食谱示例

| 餐次 | 食物 | 营养素 |
|------|------|--------|
| 早餐 | 燕麦+鸡蛋+牛奶 | 碳水+蛋白质 |
| 午餐 | 鸡胸肉+糙米+蔬菜 | 蛋白质+碳水+纤维 |
| 训练前 | 香蕉+蛋白粉 | 快速能量+蛋白质 |
| 晚餐 | 牛肉+红薯+沙拉 | 蛋白质+碳水+纤维 |
