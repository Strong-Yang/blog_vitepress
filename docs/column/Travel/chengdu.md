# 成都

## 概览

成都，四川省省会，古称"蓉城"，是一座历史文化与现代繁华并存的城市。"天府之国"的美誉让无数游客为之向往，悠闲的生活节奏和诱人的美食文化更是成都的独特魅力。

## 地理与气候

- **地理位置**：四川省中部，成都平原腹地
- **地形特点**：西依邛崃山脉，东临龙泉山
- **气候**：亚热带季风气候，四季分明，湿润宜人

## 美食推荐

- **火锅**：成都美食的灵魂，麻辣鲜香
- **串串香**：街头巷尾的经典小吃
- **担担面**：麻辣鲜香的川味面食
- **龙抄手**：成都老字号小吃
- **钟水饺**：红油水饺，口感独特
- **兔头**：成都特色小吃，麻辣入味

## 旅行建议

- 最佳旅行季节：春季（3-6月）和秋季（9-11月）
- 建议游玩天数：4-6天
- 交通：地铁覆盖主要景点，公交便利，共享单车方便
