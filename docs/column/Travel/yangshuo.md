# 阳朔

## 概览

阳朔，位于广西桂林市，以其绝美的喀斯特山水风光闻名天下。"桂林山水甲天下，阳朔山水甲桂林"，这里是骑行、漂流、徒步的天堂。

## 地理与气候

- **地理位置**：广西壮族自治区桂林市阳朔县
- **地形特点**：典型的喀斯特地貌，山清水秀
- **气候**：亚热带季风气候，四季温和

## 活动推荐

- **骑行**：租一辆自行车，沿十里画廊慢慢骑行
- **漂流**：漓江或遇龙河竹筏漂流
- **徒步**：兴坪到九马画山段
- **攀岩**：阳朔是中国攀岩胜地
- **印象刘三姐**：张艺谋导演的大型山水实景演出

## 美食推荐

- **啤酒鱼**：阳朔特色名菜
- **桂林米粉**：早餐必备
- **田螺酿**：当地特色酿菜
- **油茶**：壮族传统饮品

## 旅行建议

- 最佳旅行季节：4-10月
- 建议游玩天数：3-4天
- 住宿推荐：西街附近或遇龙河畔民宿
