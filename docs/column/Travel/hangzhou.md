# 杭州

## 概览

杭州，浙江省省会，古称"临安"，是一座历史文化与现代繁华并存的城市。"上有天堂，下有苏杭"，西湖的美景让无数文人墨客为之倾倒。

## 地理与气候

- **地理位置**：浙江省北部，钱塘江下游
- **地形特点**：西依天目山，东临杭州湾
- **气候**：亚热带季风气候，四季分明

## 美食推荐

- **西湖醋鱼**：杭帮菜代表
- **东坡肉**：苏东坡发明的名菜
- **龙井虾仁**：茶香与虾鲜完美结合
- **知味小笼**：杭州老字号
- **片儿川**：杭州特色面食

## 旅行建议

- 最佳旅行季节：春季（3-5月）和秋季（9-11月）
- 建议游玩天数：3-5天
- 交通：地铁覆盖主要景点，公交便利
