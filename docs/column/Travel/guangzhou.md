# 广州

## 概览

广州，广东省省会，古称"羊城"，是一座历史文化与现代繁华并存的城市。"食在广州"的美誉让无数游客为之向往，独特的岭南文化和繁荣的商业氛围更是广州的独特魅力。

## 地理与气候

- **地理位置**：广东省中南部，珠江三角洲北缘
- **地形特点**：北依白云山，南临珠江
- **气候**：南亚热带季风气候，四季温暖湿润

## 美食推荐

- **早茶**：广州饮食文化精髓，虾饺、烧麦、叉烧包
- **白切鸡**：粤菜经典，皮爽肉滑
- **煲仔饭**：锅巴香脆，腊味浓郁
- **肠粉**：广州特色早餐，滑嫩可口
- **双皮奶**：顺德名甜，奶香浓郁
- **云吞面**：鲜虾云吞，汤鲜面滑

## 旅行建议

- 最佳旅行季节：春季（3-5月）和秋季（10-12月）
- 建议游玩天数：3-5天
- 交通：地铁网络发达，公交便利，出租车方便
