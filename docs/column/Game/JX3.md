# 剑网三 (剑侠情缘网络版叁)

## 开发与发行
- **开发商**: 西山居 (Seasun)
- **发行日期**: 2009年8月28日
- **游戏类型**: 大型多人在线角色扮演游戏 (MMORPG)
- **平台**: PC

## 游戏背景
- **世界观**: 架构于唐朝安史之乱的历史背景之上，融合武侠与江湖情义
- **剧情特色**: 以江湖门派纷争为主线，玩家可选择十大门派，体验恩怨情仇

## 游戏特色
- **轻功系统**: 飞檐走壁，空中连跳，江湖感十足
- **外观系统**: 时装、挂件、坐骑丰富，外观党福利
- **副本玩法**: 五人本、团队本，挑战各种BOSS
- **PvP竞技**: 名剑大会、战场、野外PK
- **家园系统**: 自建房屋，装修布置，休闲玩法
- **外观交易**: 游戏内外观可交易，形成了独特的经济体系
