## 🎯 我是谁？

嗨！我是 Optimux，一个热爱生活的多面手。喜欢旅游、玩游戏、拼高达、健身，用博客记录这些爱好和成长历程。

- **手工**：高达模型爱好者，享受从零件到成品的蜕变
- **健身**：力量训练与饮食管理，追求更健康的体魄
- **学习**：持续学习新技术，记录成长点滴
